Write the workflow in Obsidian. Get a chatbot.

An agent's job (its steps, tools and rules) lives in an ordinary Obsidian note. Workflow Copilot compiles the note into an agent and runs it: with the Microsoft Agent Framework behind a Microsoft 365 Agents SDK endpoint (Teams, Copilot, Agents Playground), or with a small model right here in your browser.

1. Obsidian noteProperties, Steps, Tools as [[links]] to tool notes, Rules, Examples. Edit it below.
2. Compiled agentSystem instructions plus only the tools the note links to, with the descriptions from the tool notes.
3. ChatbotMicrosoft Agent Framework + M365 Agents SDK with a local model (Ollama), or WebLLM in the browser.

The note, and the agent it compiles to

Change a step or a rule and the agent on the right updates instantly. The chat below uses whatever is in this box.

Compiled agent

Chat with it

A small open model runs on your own graphics card through WebGPU (WebLLM): no server, nothing sent anywhere. The first load downloads the model (about 2 GB for 3B, a few minutes); your browser keeps it, so later loads take seconds.

Try the note's examples

How the browser bot works: for each message the model picks a tool from the note (the choice is constrained to valid JSON), the tool runs in the page, and the model writes the answer from the result. The first action is always one of the note's tools, since small models otherwise answer from memory. A 3B model is still much weaker than the 8B one in the recorded runs; that gap is the point of the comparison.

Run the same note in Microsoft 365

The Python package compiles the same note and serves it with the Microsoft 365 Agents SDK; any OpenAI-compatible model works (Ollama locally, vLLM, or Azure OpenAI).

pip install -e .
ollama pull qwen3:8b
workflow-copilot chat  "vault/GPU Sizing Assistant.md"     # terminal chat
workflow-copilot serve "vault/GPU Sizing Assistant.md"     # http://localhost:3978/api/messages
# then connect Microsoft 365 Agents Playground (local, no Azure account) to that endpoint;
# registering an Azure Bot puts the same app in Teams and Microsoft 365 Copilot.

Tool data is real: the GPU planner is Local Inference Lab's (demo), and filing answers were recorded from Filings RAG (demo). Built by Howard Guo.
